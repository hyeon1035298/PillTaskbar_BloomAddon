# Which paths go into the public PillTaskbar_BloomAddon repository.
# Globs are relative to the repository root. One reason per line.

[public]
LICENSE                      GPL-3.0-only text, required for distribution
README.md                    English readme
README.ko.md                 Korean readme
THIRD_PARTY.md               credits and licenses of code taken from other mods
pill-taskbar.wh.cpp          the mod, used by Windhawk and by the add-on (no company logos)
docs/addon-protocol.md       the files and events the host, the runtime and Bloom agree on
addon/**                     add-on entry file and manifest source
common/**                    protocol header shared by host and runtime
runtime/**                   Windhawk API subset the mod links against
host/**                      injector and symbol resolver
third_party/**               MinHook (BSD-2-Clause) and Zydis (MIT) with their license files
tools/build-addon.sh         the build
tools/make-schema.py         generates the settings schema and defaults header
tools/names-en.tsv           English names for the settings schema
tools/make-manifest.py       writes addon.json for the bundle
tools/make-identity.py       turns addon/addon.conf into the names header and identity.json
tools/symbol-list.py         builds symbols.txt and symbols-meta.txt from the mod
tools/port-sources.txt       older published builds the host may port symbols from
tools/port-sources.py        copies an add-on's lines of that list into its bundle
tools/check-public.py        pre-commit check for personal data
tools/check-release.py       checks an add-on release the way Bloom installs it
tools/public-files.txt       this list
.github/workflows/build.yml  CI build and release zip
.gitignore                   keeps private output out
.gitattributes               line endings

[private]
docs/** but addon-protocol   private notes
.work/**                     scratch copies and local build trees
build/**                     build output, regenerated by CI
sandbox/**                   local tests
_backup/**                   local backups
work/**                      not part of this project
*.pdb                        debug symbols, never published
offsets/**                   per-machine offset tables from Microsoft symbols
names-*.txt                  symbol dumps from local runs
tools/build.sh               old Windhawk-side build helper (Windhawk builds the mod itself)
tools/compare_cache.py       compares against a local Windhawk cache, dev only
tools/pe_imports.py          local import check, dev only
tools/*harness*              test harnesses that need an explorer test setup
tools/crash-test-mod.cpp     deliberate crash test, dev only
tools/disasm-check.cpp       local disassembly check, dev only
tools/windhawk-values.py     reads the local Windhawk registry, dev only
